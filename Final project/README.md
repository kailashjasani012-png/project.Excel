## 📌 About the Project

**PR. Final Project — Data Intelligence Dashboard** is a comprehensive, multi-sheet Excel practice project designed to demonstrate advanced data analysis, dynamic reporting, modeling, and executive dashboard design. Starting from raw customer transaction records, the workbook expands into separate pivot tables, statistical summaries, date calculations, and what-if scenarios.

Every sheet is formula-linked to the core dataset, ensuring that updates flow seamlessly across all summaries and charts.

---

## 🎯 Objective

Create a full-fledged analysis and reporting solution using Excel to analyze customer transactions, uncover actionable business insights, and build professional data visualizations and dashboards with separate pivot tables and advanced functions.

---

## 🗂️ Workbook Structure

| Sheet Name | Description |
|---|---|
| **Dashboard** | Executive KPI summary cards, regional revenue chart, and product category distribution. |
| **Final Project Dataset** | Raw transaction log containing 200+ customer transaction records (IDs, dates, prices, quantities, discounts, status). |
| **Pivot Tables** | Dedicated separate sheet containing pivot summary tables for Regional Performance and Product Category breakdown. |
| **Analysis & Formulas** | Advanced date functions (`TODAY`, `NOW`, `DATEDIF`, `EOMONTH`), FILTER, GroupBy/SUMIF, What-If Scenarios, and Text functions. |

---

## 🧠 Key Topics Implemented

- ✅ **Date & Time Functions:** `TODAY`, `NOW`, `DATEDIF`, `EOMONTH` for dynamic tracking and project span calculation.
- ✅ **FILTER Function:** Dynamic multi-value returns for filtered regional data views.
- ✅ **Conditional Formatting:** Icon sets and color scales for visual indicator highlights.
- ✅ **Timestamps:** Built using `NOW()` for real-time recalculation monitoring.
- ✅ **What-If Analysis:** Scenario Manager setup for evaluating discount rate adjustments and revenue variance.
- ✅ **Linear Regression:** Sales trend projection utilizing Data Analysis Toolpak concepts.
- ✅ **GroupBy & Customer Segmentation:** Formulas to identify high-value VIP customers and purchase totals.
- ✅ **Dashboard Design:** Clean layout with KPI indicator cards, charts (Bar & Pie), and structured hierarchy.
- ✅ **Text & Lookup Functions:** `UPPER`, `LEFT`, `TEXT`, `MATCH`, `XLOOKUP`, and frequency checking via `MODE`.

---

## 📊 Dashboard Highlights

- **Total Revenue:** Comprehensive tracking across all regions and product lines.
- **Total Transactions & Units Sold:** Volume monitoring for operational performance.
- **Average Order Value:** Financial health indicator per transaction.
- **Regional Breakdown:** Comparative visual analysis of North, South, East, West, and Central markets.

## 🚀 How to Use

1. **📥 Download** the workbook: `Data_Intelligence_Dashboard_Final_Project_v3_2.xlsx`
2. **📂 Open** it in Microsoft Excel or Google Sheets.
3. **📊 Review** the `Dashboard` sheet first for high-level executive insights.
4. **🔍 Explore** the `Pivot Tables` sheet for aggregated cross-tab summaries.
5. **⚙️ Check** the `Analysis & Formulas` sheet to inspect implementation formulas, date calculations, and what-if models.
6. **📋 Reference** `Final Project Dataset` for raw transactional records.
